# Anomaly-Detection
Поиск киберугроз и аномалий в поведении пользователей с помощью One-Class SVM. Включает сложный Feature Engineering логов (анализ IP, bash-команд) и обработку несбалансированных данных.

Датасет взят с платформы Kaggle.

## Стек технологий
* Language: Python
* Libraries: Scikit-learn, Pandas, NumPy, StandardScaler

## Особенности архитектуры решения
Главная сложность датасета заключалась в том, что аномальные события (атаки) численно превосходили нормальные действия пользователей. Для решения этой проблемы использовалась модель One-Class SVM, что обучается исключительно на профилях нормального поведения, чтобы изолировать и определять любые отклонения как угрозу.

## Этапы работы
* Сбор признаков (Feature Engineering): вычисление частоты появления IP-адресов, парсинг и выделение bash-команд, подсчет количества событий и процента ошибок от общего числа действий с одного IP итд
* Масштабирование числовых признаков с помощью StandardScaler
* Фильтрация данных и обучение модели One-Class SVM на чистой выборке нормального поведения
* Проверка модели на тестовой выборке, содержащей как норму, так и различные типы аномалий

## Результаты
Модель успешно изолировала и идентифицировала абсолютное большинство критических киберугроз:
* Brute-Force атаки: обнаружено 37 749 из 37 749 (100% обнаружения)
* Brute-Force с сетевыми проблемами: обнаружено 367 из 367
* Ложноположительные срабатывания (ошибки на норме): всего 183 из 3 707 нормальных сессий
